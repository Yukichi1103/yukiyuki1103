# Diamond Sales AI

AI営業アシスタント - 営業に必要な文章を自動生成するWebアプリ

## 概要

Diamond Sales AIは、企業名、業種、商品・サービス、営業相手の情報を入力すると、営業に必要な文章を自動生成できるWebアプリケーションです。

### 生成可能な文章

1. **営業メール** - 新規営業に最適な初期接触メール
2. **電話営業スクリプト** - 電話営業用の実践的なトークスクリプト
3. **フォローメール** - 商談後のフォローアップメール

## 技術スタック

- **フレームワーク**: Next.js 15
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **ルーティング**: App Router
- **レスポンシブ対応**: モバイル・タブレット・デスクトップ対応

## 機能一覧

- ✅ 企業名の入力
- ✅ 業種の選択（プリセット業種）
- ✅ 自社の商品・サービスの入力
- ✅ 営業相手の役職入力

- ✅ ワンクリックで営業文章を生成
- ✅ 生成結果をクリップボードにコピー
- ✅ 入力内容をリセット
- ✅ タブ切り替えで異なる文章を表示
- ✅ モダンで使いやすいUI/UX

## セットアップ手順

### 1. 必須要件

- Node.js 18.0 以上
- npm または yarn

### 2. インストール

```bash
# リポジトリをクローン（または develop ブランチをチェックアウト）
cd yukiyuki1103

# 依存パッケージをインストール
npm install
# または
yarn install
```

### 3. 開発サーバーの起動

```bash
npm run dev
# または
yarn dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開くと、アプリが表示されます。

### 4. ビルド（本番用）

```bash
# 本番用にビルド
npm run build

# ビルド後の本番サーバーを起動
npm start
```

## 使い方

### 基本的な操作フロー

1. **左のフォームに情報を入力**
   - 企業名（必須）
   - 業種（必須）
   - 自社の商品・サービス（必須）
   - 営業相手の役職（必須）
   - 営業相手の悩み・課題（必須）

2. **「営業文章を生成」ボタンをクリック**
   - 自動的に3種類の文章が生成されます

3. **生成された文章を確認**
   - タブを切り替えて「営業メール」「電話営業スクリプト」「フォローメール」を確認

4. **コピーボタンで文章をコピー**
   - 「クリップボードにコピー」ボタンをクリック
   - クリップボードに文章がコピーされます

5. **内容を編集・使用**
   - コピーした文章をメールクライアントやテキストエディタに貼り付け
   - 必要に応じて内容を編集して使用

6. **リセット**
   - 「リセット」ボタンで全ての入力をクリアして新しい営業文章を生成

## デザイン特徴

- **色彩**：白、黒、青を基調とした落ち着いた配色
- **レイアウト**：左に入力フォーム、右に出力結果の2カラムレイアウト
- **レスポンシブ**：モバイルでは1カラムに自動切り替え
- **アクセシビリティ**：視認性の高いフォントサイズと色コントラスト
- **UX**：リアルタイムフォーム検証とローディング状態の表示

## カスタマイズ方法

### 業種の追加

`components/InputForm.tsx` の業種セレクトボックスに業種を追加：

```tsx
<option value="新業種">新業種の表示名</option>
```

### 文章テンプレートの変更

`lib/contentGenerator.ts` の以下の関数を編集：

- `generateEmail()` - 営業メールのテンプレート
- `generatePhoneScript()` - 電話営業スクリプトのテンプレート
- `generateFollowUpEmail()` - フォローメールのテンプレート

### 色の変更

`tailwind.config.ts` のカラー設定を編集：

```ts
colors: {
  primary: {
    // 色値を変更
  },
}
```
